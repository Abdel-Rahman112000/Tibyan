# تبيان

واجهة أكاديمية ناشئة لتعلّم القرآن عن بُعد، بالعربية والإنجليزية، مع تجربة لطلب التحاق الطالب واختيار البرنامج والمعلم وساعة التعلم الأسبوعية.

> تجربة الالتحاق الحالية معاينة فقط. لا تحفظ بيانات الطلاب ولا تحجز المواعيد. الباك اند ولوحة التحكم والدفع ستُربط لاحقًا.

شغّل المشروع:

```bash
npm install
npm run dev
```

افتح `http://localhost:3000/ar`. للتفاصيل الكاملة عن الصفحات والبيانات والقواعد وخطة الباك اند، اقرأ [دليل المشروع](./PROJECT_GUIDE.md).
